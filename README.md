# Caesar Cipher

## About the Project

I created this Caesar Cipher program as part of Day 8 of my 100 Days of Python course. The program allows users to encode and decode messages by shifting letters through the alphabet.

The main goal of this project was to get more comfortable using Python functions, loops, conditional statements, and lists.

## How the Program Works

The program asks the user whether they want to encode or decode a message. After entering their message, the user chooses how many positions they want to shift the letters.

The program then shifts each letter based on the number entered and displays the new message. Numbers, spaces, and symbols stay the same. The user can also choose to restart the program or exit.

## Python Concepts I Used

- **Functions:** Handles encoding and decoding messages.
- **For Loops:** Goes through each letter in the message.
- **While Loops:** Allows the program to run multiple times.
- **If/Else Statements:** Controls how the program handles different inputs.
- **Lists:** Stores the letters of the alphabet.
- **String Manipulation:** Builds the encoded or decoded message.
- **Modulo Operator (%):** Keeps the letters within the alphabet when shifting.

## What I Learned

Working on this project helped me understand how functions work and how to use parameters to pass information into them. I also learned how to use the modulo operator to shift letters without going outside the alphabet.

I got more practice using loops, lists, and conditional statements to make a program work based on what the user enters. This project helped me improve my understanding of Python and how to organize my code.
